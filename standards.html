Rigor

Coding Standards

PSR-12 · Naming Conventions · Security First · Semantic HTML · Modern JavaScript

PSR-12 Compliance

Indentation & Braces
4 spaces — no tabs
Opening braces on the next line for classes/methods, same line for control structures.
Line Length
Soft limit 120 chars, hard limit 120
Split long lines for readability.
Visibility
Always declare visibility (public/protected/private)
No var. Abstract and final declared before visibility.
Control Structures
Space after keyword, space before/after operators
if ($condition) { — no Yoda conditions unless necessary.

Security Standards

Validation
All user input validated via $request->validate() in controllers.
CSRF Protection
@csrf in all forms. X-CSRF-TOKEN header in AJAX requests.
SQL Injection
Use Eloquent/Query Builder with parameter binding. Never raw string concatenation.
XSS Prevention
Escape output with {{ }} in Blade, textContent in JS.
Mass Assignment
$fillable defined on every model.
Authorization
Policies + @can directives. abort(403) for ownership checks.
Environment Config
Sensitive config in .env only — never hardcoded.
File Uploads
Validate by type and size. Store outside public root.

HTML Standards

Document Structure
Always include <!DOCTYPE html> and html lang="en".
Semantic Elements
header, nav, main, article, section, footer — use the right tag for the job.
Indentation
4 spaces. Double quotes for all attribute values.
Accessibility
Every img has alt text. Every input/textarea/select has an associated label.
Required Fields
Include asterisk (*) in labels where the input has the required attribute.
JS Hooks
Use data-* attributes for JS hooks — never IDs for styling or behaviour.

JavaScript Standards (ES6+)

Variables
const by default. let only when reassignment needed. Never var.
Functions
Arrow functions for callbacks. async/await with try/catch for all async operations.
DOM Queries
Cache DOM queries. Use event delegation for dynamic content.
Event Handlers
addEventListener only — no inline handlers.
AJAX / Fetch
Proper error handling on every call. X-CSRF-TOKEN header required on all non-GET requests.
Performance
Debounce/throttle high-frequency events (scroll, resize, input).

CSS Standards

Architecture
Bootstrap first, custom CSS only when needed. No inline styles ever.
Organization
Organised by component/feature. Keep specificity low.
Theming
CSS custom properties for theming (defined under :root).
No Style Attributes
No text-muted, small, or bg-* classes in Blade/HTML. CSS handles all styling.
Theme
Dark theme — Black / Gold.
Responsive
Mobile-first. Bootstrap grid: row, col-, col-sm-, col-md-.

Error Handling & Logging

Try/Catch
Wrap transactions and file operations in try/catch.
User Messages
Show friendly, non-technical messages to users.
Logging
Use Log::error() with context for server-side logging.
