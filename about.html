Background

About Me

I'm a Senior Full-Stack Laravel Developer operating under KodaKodra. Since 2019 I've built web applications with deep focus — but more importantly, I bring strong data analytics and SQL optimisation skills that turn raw data into actionable insights.

My core stack: Laravel, PHP 8.5+, MySQL, Bootstrap. I design normalised database schemas, architect role-based systems, write clean Eloquent, and build responsive front-ends that work on mobile. Every project follows disciplined workflow: Migration → Model → Policy → Controller → Routes → Views.

Security is a mindset: CSRF, XSS prevention, mass-assignment protection, parameterised queries — all baseline. I think about abuse vectors before writing code.

My biggest current project: a community social network built in Laravel (posts, privacy controls, points economy, leaderboard). But equally important: I develop custom analytics dashboards that help stakeholders monitor KPIs, revenue trends, and user engagement — merging back-end logic with visual clarity.

Outside code, I hold a Level 3 qualification in Team Leading & Management and 20+ years of customer-facing experience — which taught me how to translate requirements into robust technical solutions.
